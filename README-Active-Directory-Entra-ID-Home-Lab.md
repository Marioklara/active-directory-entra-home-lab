# Active Directory \& Microsoft Entra ID Home Lab

Dieses Repository dokumentiert mein eigenes IT-Home-Lab mit Windows Server, Active Directory und Microsoft Entra ID.

## Ziel

Ich habe eine kleine Unternehmensumgebung aufgebaut, um typische Aufgaben aus Systemintegration, IT-Support und Administration praktisch zu ueben.

## Inhalte

* Hyper-V Umgebung mit AD-Server, Client und Fileserver
* Active Directory mit OUs, Benutzern und Gruppen
* Gruppenmitgliedschaften und Berechtigungsprinzip
* Fileserver mit Freigabe- und NTFS-Berechtigungen
* DNS-Konfiguration mit Weiterleitungen
* DHCP-Scope und Reservierung
* Gruppenrichtlinie zum Sperren der Systemsteuerung
* Client-Test zur Pruefung der GPO
* Microsoft Entra ID Benutzerverwaltung und erste Cloud-Identitaetsverwaltung
